# Interface context

Operate mode. The extraction inherits the original Work Center's functional vocabulary and light blue-and-white visual language; this is a compact adapter, not a rebrand. System UI font is retained for offline portability. Background #f6f8fb; white surfaces; ink #172033; action blue #2459b8; secondary ink #536176; dividers #dce4ef. Use a persistent navigation rail on desktop and horizontal navigation on small screens. Job list and inline detail form keep context visible. Controls have visible labels, focus rings, pending/error/empty states, and minimum 42px heights. Status labels use words as well as color. No external fonts, assets, or network UI dependencies.

Desktop and 390px layouts were visually inspected. This file documents the inherited visual approach and does not establish a new branding system.
